SIL Open Font License (OFL) 1.1 — fonts used by Jokguboard

This project does not embed font binaries. The web UI loads the following
families from Google Fonts (CSS stylesheet only):

  - Noto Sans KR  https://fonts.google.com/noto/specimen/Noto+Sans+KR
  - Jua           https://fonts.google.com/specimen/Jua
  - Do Hyeon      https://fonts.google.com/specimen/Do+Hyeon
  - Orbitron      https://fonts.google.com/specimen/Orbitron

All four families are published under the SIL Open Font License 1.1.
No GPL font or GPL JavaScript library is included.

If the stylesheet cannot load (offline APK without network), the UI falls
back to system UI fonts (not claimed as OFL).
