## 목표

웹 정적 점수판과 Android WebView APK로 족구·Futnet 경기를 현장에서 집계한다.

## 규칙 (현재)

### 족구 (`jokgu`)

- 코트 선수 4명. 한 세트 15점, 2점 차. 14:14부터 듀스.
- 랠리 득점: 서브 팀·리시브 팀 모두 +1 가능.
- 사이드아웃: 리시브 팀이 득점하면 서브권이 넘어간다. 직전 서브 팀만 다음 번호(1→2→3→4). 서브 팀이 연속 득점하면 번호 유지.
- 상대가 먼저 득점하면 그 팀 1번부터 서브.
- 원 숫자 1·2·3·4는 슬롯에 고정. 서브 표시는 금색 배경과 더 큰 원·숫자.
- 원 위치: 점수 위·아래. 화면 왼쪽 위 3·4 / 아래 2·1, 오른쪽 위 1·2 / 아래 4·3. 위·아래 원은 같은 세로줄로 점수 가운데에 모음. 선서브 금색은 1번부터.
- 가운데 세트 칸 글자는 칸 크기에 맞춤. 세트 점수는 남은 칸을 채움. 현재 시각·경기 시간(선서브부터). 새 경기 글자는 버튼에 맞춤.
- 경기는 3세트 2선승만 (`bo3_2`).

### Futnet (`futnet`)

- 한 세트 11점, 2점 차, 최대 15점(15:14 종료).
- 항상 3세트 2선승.
- 싱글 1인 / 더블 2인 / 트리플 3인(기본 더블).
- 방금 득점한 팀이 서브. 강제 회전 없음.
- 더블·트리플: 원 탭으로 서브 선수 표시. 싱글: ①만, 그 팀 점수 짝수 R / 홀수 L(0점은 R).

### 공통

- 0:0에서 선서브 선택(원·화면 좌우·패드 위·아래). 팀명 터치는 이름 수정.
- 팀명은 가운데 세트 쪽(사이버 스킨은 위 가운데), 글자 크기 2배.
- 세트 종료 후 코트 교대(`teamsSwapped`). 안내 창은 5초 후 자동으로 닫힘(확인 없음). 세트 안내 중에도 패드 득점.
- 경기 종료 창: 확인(결과 유지) 또는 새 경기(선서브 팀 선택 후 초기화).
- 새 경기 카드: 취소 또는 청/백 선서브. 선서브를 고르면 바로 패드로 득점 가능.
- 종목 또는 Futnet 유형 변경 시 확인 후 현재 점수 초기화.

## 포함 (현재)

- 가운데 세트 칸: 「세트」·서브 안내·시각·경기 시간은 칸 비율, 세트 점수는 남은 칸, 새 경기 글자는 버튼에 맞춤. 경기 시간은 선서브부터, 새 경기에서 0.
- 설정: 종목, Futnet 유형, 언어, 글꼴, 보드 모습, 점수 읽기
- 심플 모드(선서브 후). 심플에서는 새 경기 숨김
- 하단 메뉴: 되돌리기 · 심플 · 설정 · 도움말
- APK 경기 중 화면 L/R +1, 길게 −1. 가운데 칸·새 경기는 L/R에서 제외
- APK 전용: 설정 맨 아래 가운데·아래 버튼 패드 위치 맞추기(이 기기 SharedPreferences). 웹에는 칸 없음. 외부 BT 음량 짧게 좌우 득점, 길게 되돌리기. 원형 미디어 짧게 되돌리기.
- 이 리모컨은 좌표 클릭이 아니라 제스처를 보낸다: 가운데·아래는 눌림→뗌 사이 경과시간·이동거리로 탭/스와이프 구분, 위는 좌표 없는 단독 시스템 터치-아웃사이드 신호로만 옴(`JK_PAD_GESTURE`)
- 패드·볼륨·미디어 키 중 같은 눌림이 두 경로로 들어와도 한 번만 반영(교차 입력 잠금). 몰입 모드 중 상태·내비 바가 살짝 보이면 다시 숨김(`JK_HID_PAD_LOCK`, `JK_HID_BAR_GUARD`)
- localStorage 키 `jokgu_scoreboard_state_v1`
- Vercel 정적 (`/` 랜딩, `/play` → `jokgu_scoreboard.html`)
- TTS: 득점·서브·세트·경기. Android `AndroidTTS`, 웹 `speechSynthesis`. MP3 팩·마이크 없음
- BLE: 기존 Score 시계와 같은 GATT 패킷 v2. Android 12+ 연결·advertise 권한
- 보드 모습: 자체 look + Score 스킨 CSS를 족구 DOM에 연결. 탁구장 PNG·카메라·liverec 없음

## 특허 검토가 필요할 수 있는 구성 (비보장)

청구항 비교는 법률 자문이 아니다. 침해 없음을 보장하지 않는다.

- 화면 좌우 점수 BLE GATT notify
- APK L/R 클릭·길게 −1
- 세트 종료 시 자동 엔드 스왑
- 점수 TTS 문구 타이밍
- 3D 스킨(원근·카드 기울기)
- 한 화면에서 종목 전환 시 점수 초기화 + 선수 원 개수 변경
- 사이드아웃 회전 vs 득점자 서브
- HID 미디어/음량 키를 점수·되돌리기에 연결
- 외부 리모컨의 눌림→뗌 사이 경과시간·이동거리로 탭/스와이프(가운데/아래)를 구분
- 좌표 없는 단독 시스템 터치-아웃사이드 신호를 특정 버튼(위) 눌림으로 해석
- 같은 물리 버튼 눌림이 서로 다른 입력 경로(터치 제스처·볼륨키)로 중복 도착할 때 한 번만 반영(교차 입력 잠금)

일반 점수 표시·15점/11점 듀스·확인 배너는 종목 규칙·관용 UI이다.
